# أداة المونتاج التلقائي 🎬

أداة تساعدك قبل ما تفتح CapCut. تعطيها فيديو الكاميرتين، وهي تعمل لك:

1. **مزامنة الكاميرتين** تلقائيًا عن طريق الصوت (ما تحتاج تصفيق ولا تطابق يدوي).
2. **قص السكتات**: تحذف الأماكن اللي ما فيها كلام.
3. **حذف كلمات الحشو** مثل: اممم، آه، هممم.
4. **التبديل بين الكاميرتين** كل عدة ثواني بشكل تلقائي.
5. **ترجمة عربية جاهزة** (ملف SRT) تستوردها في CapCut.

## ماذا ستحصل؟

مجلد جديد بجانب الفيديو اسمه `اسم-الفيديو_مونتاج` وفيه:

| الملف | ماذا تفعل به |
|---|---|
| `الفيديو_النهائي.mp4` | فيديو كامل مقصوص ومرتب. افتحه في CapCut وأضف عليه النصوص والمؤثرات والموسيقى. |
| `مقاطع/` | كل قصة في ملف لوحده ومرقمة بالترتيب (`001_كاميرا1.mp4`، `002_كاميرا2.mp4`...). لو تريد تتحكم أكثر، اسحبها كلها إلى CapCut وستنزل بالترتيب الصحيح. |
| `ترجمة.srt` | ترجمة الكلام بالعربي على توقيت الفيديو النهائي. في CapCut: من قسم النصوص/الترجمة اختر استيراد ملف ترجمة (Import captions). |
| `تقرير.txt` | كل قصة: من أي كاميرا، ومن أي دقيقة في الأصل. |
| `النص_الكامل.txt` | كل الكلام مكتوبًا، مفيد للعنوان والوصف. |

## التثبيت (مرة واحدة فقط)

### ويندوز
1. ثبّت **Python** من [python.org](https://www.python.org/downloads/). أثناء التثبيت ضع علامة ✅ على **Add Python to PATH**.
2. ثبّت **ffmpeg**: افتح "موجه الأوامر" (cmd) واكتب:
   ```
   winget install ffmpeg
   ```
3. نزّل هذه الأداة (زر **Code** ثم **Download ZIP** في GitHub) وفك الضغط.
4. في نفس المجلد افتح cmd واكتب:
   ```
   pip install -r requirements.txt
   ```

### ماك
```
brew install python ffmpeg
pip3 install -r requirements.txt
```

## طريقة الاستخدام

### الأسهل (ويندوز)
حدد فيديو الكاميرتين معًا، واسحبهما وأفلتهما فوق ملف **`شغل.bat`**. انتظر حتى يكتب ✅ انتهى.

### من سطر الأوامر
```
python montage.py كاميرا1.mp4 كاميرا2.mp4
```
كاميرا واحدة فقط؟
```
python montage.py فيديو.mp4
```

> **ملاحظة:** الصوت في الفيديو النهائي يؤخذ من الكاميرا الأولى. لو صوت الكاميرا الثانية أنظف أضف `--audio-from 2`، ولو عندك مايك منفصل أضف `--audio ملف-الصوت.wav`.

> أول تشغيل يحمّل نموذج تفريغ الكلام من الإنترنت (حوالي 500 ميجا)، وبعدها يشتغل بدون تحميل.

## خيارات للتحكم

| الخيار | ماذا يفعل |
|---|---|
| `--switch-every 5` | بدّل بين الكاميرات كل 5 ثواني تقريبًا (الافتراضي 7) |
| `--min-silence 0.4` | اقطع حتى السكتات القصيرة (الافتراضي 0.6 ثانية). رقم أكبر = قص أخف |
| `--pad 0.25` | اترك هامش أكبر قبل وبعد الكلام حتى لا يكون القص حادًا |
| `--remove-yaani` | احذف أيضًا: يعني، طيب، خلاص |
| `--extra-fillers "بس,اوكي"` | كلمات إضافية تريد حذفها |
| `--model medium` | تفريغ أدق للعربي لكنه أبطأ (الافتراضي small) |
| `--no-transcribe` | أسرع بكثير: يقص السكتات ويبدل الكاميرات فقط، بدون حذف حشو أو ترجمة |
| `--silence-db -45` | لو الأداة قصت كلامًا هادئًا، جرب رقمًا أصغر مثل -45 أو -50 |
| `--no-render` | لا تصدّر فيديو، فقط التقرير والترجمة (للتجربة السريعة) |

## نصائح للتصوير
- شغّل الكاميرتين مع وجود صوت في كل واحدة (حتى لو ضعيف)، لأن المزامنة تعتمد على الصوت.
- اترك ثانية سكوت بين الجمل لو أخطأت وأعدت، حتى تقص الأداة المكان بسهولة.
